**Lessons:**
- **Azure pay-as-you-go has no hard spending limit.** The Anthropic console had one. The budgets
  only alert, and late. What replaces the hard stop is an order and a cap:
  1. budgets before the resource;
  2. a token count as the only Phase 0 call;
  3. the router's in-code cap from Phase 2.

  This is the biggest real cost of the switch, and it is written down rather than glossed over.
- **A Foundry resource's name is its address.** So the name joins rule 6's list, and the check
  takes the name and builds the URL itself. This also keeps CodeQL's URL-substring rule (the
  PR #2 lesson) from having anything to flag.
- **The plan review earned its keep.** It caught that Foundry has no free models-list call. It
  also caught that a fake test host without `xxxx` would fail the PR's history scan, and that
  `FakeHttp`'s backstop could hide a leaked key behind a plain FAIL.

## THL-23: the ceiling is ₹1,500 a month (ADR-0013)

**Azure live check:** Roshan's `az login` needed `az account clear` first, because the CLI still held the
expired August login. What it showed, read-only and with no IDs printed:
- **Subscription:** pay-as-you-go, spending limit off.
- **Billing:** a Microsoft Customer Agreement in India, billed in **INR**.
- **The AI-103 Foundry account:** 0 deployments.
- **Claude Haiku 5.5:** offered as Global Standard in East US 2 and West US 3.
- **India:** on Anthropic's supported list.

**The catch:** Azure budgets are set in the billing currency. ADR-0008's $100 and $20 came out at about
₹9,500 and ₹1,900, at Azure's own rate of about ₹95 to the dollar. Roshan said the most he can spend is
₹1,500 a month. So the ceiling moved to rupees, with the same shape as before:

| | Amount |
|---|---|
| Ceiling | ₹1,500 |
| Planned spend | under ₹750 |
| Alarms | ₹1,050 and ₹1,275 |
| Brake | ₹1,425 |
| Model budget | ₹1,000 |
| Router cap | $10 |

**What it changes later:**
- Phase 7 cannot run anything all month (an Arm VM is about ₹4,700), so hosting is on demand only.
- Phase 2 adds an automated brake that removes the deployment at the ₹1,425 alert, because alerts alone
  don't stop anything.

**Lesson:** a budget written in dollars was an assumption about the invoice. Read the billing currency
before writing an amount. An alarm above what the owner can pay is not an alarm.
