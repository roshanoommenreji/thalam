# 2026-11-23

## THL-26: the CI to CD flow on the dashboard

**Asked:** "can you tell me if the end to end ci cd pipeline built and automated?", then "so for
this project do we have lower and prod separate env? explain the ci to cd flow", then "add the CI
to CD flow to the dashboard".

**The answer first:**
- **CI is built and automated.** Five checks run on every pull request and on `main`, and the
  ruleset requires all five by name.
- **CD is not built, by design.** There is no service to ship until Phases 1–6 build one.
  Phase 7 builds Kaval's pipeline on Azure: build once, staging on demand, promotion by digest.
  Kaval already runs `release.yml`, `promote.yml` and `rollback.yml`.
- **There are no lower and prod environments yet.** The only infrastructure is the guardrails'
  resource group. local, staging and prod are designed (ADR-0002) and arrive in Phase 7.
- **Cost:** inside the ₹1,500 ceiling nothing runs all month, prod included. Prod will be started
  for demos and drills and then parked.

**Built (`architecture.toml` and the DevOps view):**
- **The graph's Phase 7 column** is now the CD path: build once, staging, the promote gate (new),
  production.
- **Two sequences:**
  - *From a merge on main to production* (13 steps): `release.yml`'s two jobs with split powers,
    the staging pull request, Flux pulling by digest, the smoke test and the passed-staging
    record, `promote.yml`'s read-only gate, and the prod pull request whose merge is the
    go / no-go.
  - *Rolling production back* (6 steps), which stops if going back would cross a database
    migration.
- **The environments table:** local, staging and prod, with where each runs, when and what it
  gets. Each state follows Phase 7 in ROADMAP.md.
- **"Kaval's pipeline, moved to Azure":** ECR becomes Container Registry, the IAM role becomes an
  Entra ID federated credential, Parameter Store becomes Key Vault. Helm, Flux, cosign, the SBOM
  and the promotion guard stay as they are.
- **Eight glossary terms:** GitOps, Flux, Helm chart, image signature, workload identity
  federation, passed-staging record, promotion guard, rollback.
- **Labelled honestly:** the file says this is the shape Phase 7 builds to, and Phase 7's spec
  fixes the details.
